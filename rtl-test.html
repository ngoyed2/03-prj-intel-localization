✅ Element Order: Elements should reorder for RTL layouts

How It Works

  • The RTL detection script watches the lang attribute on the <html> element
  • When you click a button, the lang attribute changes
  • The MutationObserver detects this change and calls applyDirection()
  • For RTL languages: dir="rtl" is set and Bootstrap RTL CSS is loaded
  • For LTR languages: dir="ltr" is set and Bootstrap LTR CSS is loaded
  • Custom CSS rules in style.css handle additional RTL-specific styling
